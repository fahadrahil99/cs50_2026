# Week 4: Memory

Problem sets from CS50x Week 4, written in C. This week covers pointers, memory, file I/O, and working with binary data like audio and images.

## Problems

- **Volume**: scales the volume of a WAV audio file by a given factor.
- **Filter (more)**: applies grayscale, reflect, blur, and edge-detection filters to 24-bit BMP images.
- **Recover**: recovers JPEG files from a raw memory card image.

## Build and run

Each problem has its own folder. From inside a folder:

    make <program>
    ./<program> [arguments]

See the README in each folder for specifics.
